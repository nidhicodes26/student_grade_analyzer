# Student Grade Analyzer
Hii!

This is my first Python project uploaded to GitHub.

The program takes marks of students and calculates the average, highest, and lowest marks. It also assigns grades based on the marks entered by the user. The final report is saved in a text file named `report.txt`.

 # What I Practiced? 
- Variables
- Lists
- Loops
- Functions
- Conditional statements (if-elif-else)
- File handling

# Files
- `student_grade_analyzer.py` - Main Python program
- `report.txt` - Generated report file
- `README.md` - Project documentation

# How to Run
Open the project folder in VS Code and run:
`student_grade_analyzer.py`


## Sample Output
Average Marks: 71.6
Highest Marks: 90
Lowest Marks: 45
